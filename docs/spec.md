# Atoms_Native — 产品需求文档（Spec / PRD）

> SDD 阶段产物 #1。本文档定义"我们要造什么"，技术实现见 `docs/design.md`。

## 1. 产品定位

**Atoms_Native** 是一个「AI Agent 驱动的应用生成平台」Demo：用户用自然语言描述一个想法，平台调度一支多智能体团队（PM / 架构师 / 工程师 / 评审）把想法变成**一个可运行的单文件 Web 应用**，并实时可视化地展示生成过程与最终成品。对标 [Atoms](https://atoms.dev/) 的核心体验——"Tell Atoms your idea and watch it build a usable app in minutes"。

**一句话**：把「想法 → 多智能体协作 → 可运行 Web 应用 → 实时预览 → 迭代精修」压缩成一个顺滑闭环。

## 2. 目标用户与角色

| 角色 | 说明 |
|------|------|
| Builder（核心用户） | 有想法、想快速看到可运行原型的人（无需写代码）。使用 Studio 生成/迭代应用。 |
| 平台本身（Agent 团队） | PM(Emma) 出需求规格 → Architect(Bob) 出架构/数据模型 → Engineer(Alex) 生成代码 → Reviewer(Mike) 自审修复。 |

## 3. 核心用户流程

```
注册/登录 → 进入 Studio → 输入想法(idea) → [Agent 流水线] → 实时活动流 + 预览
   → 对话式精修("把按钮改成蓝色") → 新版本 → 保存到 Gallery
   → （延展）Race Mode 多模型择优 → 选定最优版 → 导出代码
```

### 3.1 基本使用流程（必含）
1. **初始化 / 注册**：账号体系（用户名+密码），JWT/session 鉴权。
2. **核心主流程**：想法输入 → 多智能体生成 → 单文件应用代码 → sandbox iframe 实时预览。
3. **数据持久化**：用户、项目、版本、对话、agent 运行记录全部落库（SQLite）。

### 3.2 延展 / 衍生能力（必含 ≥1，本 Demo 实现 2 个 + 1 bonus）
- **A. 对话式迭代精修**（核心延展）：基于上一版代码增量修改，保留版本历史。
- **B. Race Mode（多模型择优）**：同一需求并行跑多个 LLM，评审打分排序，用户选最优。
- **C. 导出代码 / 同步 GitHub**（bonus）：把生成的单文件应用导出下载。

## 4. 功能清单

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 鉴权 | 注册、登录、登出、Bearer 鉴权 | P0 |
| Studio | 想法输入、触发生成、实时活动流 | P0 |
| 生成 | 多智能体流水线（PM→Architect→Engineer→Reviewer） | P0 |
| 预览 | sandbox iframe 渲染生成的应用，可交互 | P0 |
| 持久化 | 项目/版本/对话/agent 审计落 SQLite | P0 |
| 精修 | 对话式迭代，版本管理 | P1 |
| Race Mode | 多模型并行 + 评审择优 | P1 |
| Gallery | 我的项目列表、重开、删除 | P1 |
| 导出 | 导出/下载生成代码（bonus） | P2 |

## 5. 验收标准（对应笔试评估维度）

- **完成度**：注册→生成→预览→精修 全链路可跑通；SQLite 持久化；基本工程质量（结构化代码、错误处理、CORS）。
- **工程思维**：任务已拆（本仓库 tasks + design）、技术选型明确（FastAPI+SQLite+原生前端，理由见 design）、复杂度受控（单文件应用生成，避免全栈爆炸）。
- **用户体验**：流程清晰（登录→Studio→预览），agent 活动流让"黑盒"变透明，预览即点即用。
- **创新性**：① 把 Atoms 的多 agent 协作**可视化**；② Race Mode 多模型择优；③ green/red-zone 安全边界（生成代码只在 sandbox iframe 跑，绝不在服务端 eval）。
- **可交付性**：README 清晰 + Docker 一键部署 + 公网可测链接 + 双远程源码。

## 6. 非目标（明确不做，控制范围）
- 不做真实支付/Stripe、不做多租户企业级权限、不做可视化拖拽编辑器（v1 用代码生成替代）。
- 不 eval 任意用户代码；生成物仅在前端 sandbox iframe 中运行。

## 7. 里程碑（建议 6–8h 专注开发）
- M1 骨架 + 鉴权 + 持久化（~1h）
- M2 LLM 注册表 + 多智能体流水线 + 实时流（~2.5h）
- M3 前端 Studio + 预览 + Gallery（~2h）
- M4 Race Mode + 精修 + 导出（~1h）
- M5 Docker 部署 + 文档 + 推送（~1h）
