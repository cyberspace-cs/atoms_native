The Immune System

摩擦信号

人机「搏斗」过的会话，会被自动记录。

你和 AI 磕磕绊绊的地方——精修失败、生成超时、结果不符——都会沉淀成回归用例。下一次同类问题出现时，测试会先一步拦住。

"让产品从自己的伤口里长出免疫力。"

HOW IT WORKS

搏斗会话 → 自动记录 → 回归用例 → CI 拦截。
