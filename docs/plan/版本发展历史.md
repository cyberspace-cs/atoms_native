## 迭代约定（怎么继续迭代）

1. **改主文档**：`docs/Atoms_Native_完整产品方案_V1.md` 是唯一的工作版（最新版），所有修改直接改它。
2. **发版存快照**：每完成一轮有意义的迭代（功能上线、方案变更、里程碑达成），把主文档复制为 `docs/plan/history/产品方案_v{主.次}_{日期}_{主题}.md`，快照内容永不改动。
3. **登记历史**：在本文件的表格最上方插入一行新版本记录。
4. **版本号规则**：结构或方向性变化升主版本（v2.0）；内容增补、事实更新升次版本（v1.1）。
5. 主文档末尾的「版本发展历史」小节只保留最近 3 条 + 指回本索引的链接，完整历史以本文件为准。
