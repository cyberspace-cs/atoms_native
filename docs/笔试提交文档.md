## 1. 挑战内容：完成一个可运行的 Atoms-Demo

**成果一句话**：[Atoms Native](https://taoxie.vip/atoms-native/) —— 一个可运行的网页应用：用自然语言描述想法 → 四个 AI 智能体（PM/架构师/工程师/评审）协作 → 生成一个可运行的单文件 Web 应用 → 实时预览 → 对话式精修。对标 atoms.dev 的核心体验，全部真实交互、数据持久化、线上可用。

- **提交时效**：收到任务后 48 小时内完成主体开发并部署上线（在线环境为腾讯云自部署：nginx 子路径 + uvicorn）。
- **工具与方式**：全程 vibe coding——Trae + GLM-5.3-Flash 驱动开发（见第 5 节），人工负责需求拆解、方向决策与逐项验收。
- **基本要求核对**：
  - ✅ 智能体驱动代码生成（非纯静态展示）：SSE 直播四智能体协作过程
  - ✅ 数据持久化：SQLite（用户/项目/版本/对话/审计轨迹全落库）+ Redis 限流
  - ✅ 基本使用流程：注册 / 登录 / 生成 / 预览 / 精修 / 回滚 / 导出
  - ✅ 延展能力：Race Mode 多模型同题竞技择优、OWASP LLM Top 10 安全扫描评分、摩擦信号→评估集闭环、发现与模板社区页、产品方案版本历史页

## 3. 简要说明文档（官方建议项）

浓缩版如下，全文见 [README](../README.md)：

- **实现思路与关键取舍**：FastAPI + SQLite（零运维单机可跑）+ 原生 JS 前端；生成产物收敛为自包含单文件 HTML，跑在无 same-origin 的 sandbox iframe 里；无 Key 时诚实降级为 mock 并显著标注，绝不伪装成功。
- **当前完成程度**：已做——生成/直播/精修/回滚/Race/导出/安全扫描/摩擦信号/看板/发现页/版本历史页（P0+P1 全部上线）；未做——真实 Stripe 支付、多租户企业权限、可视化拖拽编辑器、评估集 50+ 例 pass@k（见 README「未做」清单）。
- **如果继续投入时间（优先级判断）**：P2 = 多页应用与可视化编辑（扩展表达力）> 导出到 GitHub（拥有构建的东西）> 更多智能体角色（能力纵深）> 评估集扩充（质量纵深）。
