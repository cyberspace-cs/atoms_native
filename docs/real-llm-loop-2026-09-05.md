# 真实 LLM 小样本闭环

## 范围与模型

用户明确授权真实调用。通过供应商 `/models` 接口核验模型标识，使用 DeepSeek 直连 `deepseek-v4-flash`。OpenRouter 目录中所列 Hy4、GLM 5.3 Flash 与 DeepSeek V4 Flash/视觉实验模型均有非零价格，未按免费模型使用，也未赛马。

测试密钥仅注入执行进程，未写入仓库。测试使用独立临时 SQLite 数据库。真实 FastAPI 路由经 TestClient 执行，Playwright 浏览器请求转发到同一应用，检查实际 Studio 沙箱；没有部署线上服务。

## 真实结果

需求：标题为“小计数器”，数字初始为 0，按钮“加一”“重置”；精修只将标题改为“今日计数”。

| 阶段 | LLM 请求 | 终态 | 离线模板 | 保存版本 | 静态安全分 |
| --- | ---: | --- | --- | ---: | ---: |
| 生成 | 4 | success | false | 1 | 96 |
| 精修 | 2 | success | false | 2 | 96 |

供应商实际 usage 合计：输入 8,708 tokens，输出 10,093 tokens，共 18,801 tokens。6 个调用全部 HTTP 200，调用耗时合计约 82.87 秒。未读取账单，不报告推算费用。

## RED → 修正 → 零调用复测

第一次执行中，生成、精修与按钮检查均通过，最后的浏览器异常检查失败。零调用回放复现：测试脚本的登录初始化同时进入 sandbox iframe，读取 localStorage 时被拒绝。

修正测试初始化脚本，仅在顶层且 origin 为本地测试地址时设置登录 token。使用保存的真实版本再回放，全部通过，新增模型调用为 0：

- 简约版输入带入 Studio；
- 两版产物标题符合各自要求；
- 每版连续点击加一两次显示 2，重置后显示 0；
- 生成和精修分别持久化，当前版本指针可正确选择；
- 浏览器 pageerror 为 0。

脚本 `scripts/real_llm_loop.py` 需要显式 `--run` 才执行真实请求，总上限 8 次；`--replay <结果目录>` 使用保存的数据库与产物，并在请求边界禁止新增 LLM 调用。未接入默认离线 CI，避免日常回归产生费用。

这是一项真实小样本验证，不代表所有应用类别的模型质量通过。原始 report.json 保留最初浏览器检查失败记录，replay-report.json 单独记录修正后通过结果，不覆盖历史失败事实。
